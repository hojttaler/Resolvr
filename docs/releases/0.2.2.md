# Resolvr 0.2.2

One environment for every tab, response values that land in variables by themselves, flows that survive renames — plus a log file to report crashes with, and fixes for the Linux menu.

## One environment per workspace

The environment and endpoint in the title bar used to belong to the tab, so two tabs could quietly send requests to different environments. The choice is now shared by all tabs of a workspace. After the update the environment of your active tab becomes the workspace choice. Opening a saved operation or a history entry no longer switches it.

## Response values in the environment

Right-click any value in the response — a string, a number, an object — and **Save to environment variable…**. Tick **Save after every run** to turn it into a rule of the operation, or manage the rules on the **To environment** tab of a saved operation. The rule is "after a successful run, store `data.login.token` in `{{token}}`". Rules run only on successful responses, can store the value as a secret, and apply to runs through MCP as well. A note above the response lists what was saved.

## Environment variables in requests

Type `{{` in the variables editor to pick a variable of the active environment or of the operation's prerequisite flow. Secret values stay masked. Names the environment does not define are underlined, and unknown names in headers are listed under the header editor.

## Collections

Operations are reordered by drag and drop, within a collection or into a specific position of another one. Renaming or moving an operation now updates the flows and login profiles that use it, and the operation keeps its place in the list.

## Response pane

- **Copy** copies the whole Response, Raw, Headers or Trace tab — the full text, not only the visible rows.
- ⌘A / Ctrl+A selects the tab content; in the JSON tree ⌘C then copies the full response.
- Huge responses: the Raw tab shows the first megabyte with **Show all**, bodies over 5 MB are not re-formatted, and search no longer blocks typing.

## Editor search

⌘F opens a redesigned find/replace panel with a match counter, case / regexp / whole-word toggles and a replace row behind the chevron. Enter and Shift+Enter move between matches, Esc closes.

## Unsaved changes

Closing a tab with unsaved changes asks **Save / Don't save / Cancel**. A new draft opens the save dialog and closes once saved.

## Logs

The app now writes a log file. It records crashes, unhandled interface errors and HTTP, Keychain and file-watcher failures. Tokens, header values and request or response bodies are never written. Open the folder from **Settings → About → Logs** or **Resolvr → Open Logs**, and attach the file to a bug report. If the interface fails to render, a recovery screen replaces the blank window.

## Fixed

- Linux: the **Window** menu did nothing, and **About Resolvr** showed an empty dialog with a broken icon. **Window** now minimizes, maximizes and closes, **F11** toggles full screen, and About shows the version, license and icon.
- Saving over an existing operation, in the app or through MCP `operation_save`, dropped its description and prerequisite flow.
