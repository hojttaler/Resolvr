# Resolvr 0.4.0

The workbench, flow editor and settings have a more compact layout and a new app
icon. Settings → Themes includes refreshed light and dark palettes, Graphite and
a catalog of local JSON themes. On macOS, workspace transparency can be enabled
separately from the window effect.

## Building requests from the schema

Selecting an operation in the Schema Explorer opens a request for it and exposes
its fields. Selecting a field inserts it into the current request. The query
editor's context menu also opens a field picker for the current selection set.
Several fields can be picked in one pass, and a depth setting controls how far
to expand nested selections when filling all fields.

The variables editor offers a corresponding picker for the input type at the
cursor. It inserts the selected input fields into the variables JSON. The
picker stays open until the selection is applied.

## Other improvements

- Schema introspection uses the selected environment, resolves authorization
  headers and can run the configured login flow.
- Context menus in editors and inputs expose formatting and clipboard actions
  where available.
- Large JSON responses require less work to display. Background draft saves are
  serialized to preserve the order of edits.
