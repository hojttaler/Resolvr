# Resolvr 0.2.4

Fixes for Linux: copying works, and the interface no longer crashes on the NVIDIA driver.

## Fixed

**Copying on Linux.** Every copy action — the response **Copy** button, "Copy value", links, curl — did nothing: WebKitGTK does not let the page write to the clipboard. Copying now goes through the app itself on every platform.

**Crashes and a blank window with the NVIDIA driver.** With the proprietary NVIDIA driver the WebKitGTK DMA-BUF renderer could crash the interface or leave the window empty, without a trace in any log. Resolvr now turns this renderer off when it detects the NVIDIA driver. If you set `WEBKIT_DISABLE_DMABUF_RENDERER` yourself, your value is kept.

**Recovery instead of an empty window.** If the WebKit page process still dies on Linux, the reason — crashed or exceeded the memory limit — is written to the log (**Resolvr → Open Logs**) and the interface reloads with your tabs and drafts.

Everything else is identical to [0.2.3](https://github.com/hojttaler/Resolvr/releases/tag/v0.2.3).
