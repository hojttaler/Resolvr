# Resolvr 0.1.0

The first public release of Resolvr — a native GraphQL client that never loses your state, keeps collections in plain files your team can share through git, and lets an AI agent work through the same engine you do.

## Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon + Intel) | `Resolvr_0.1.0_universal.dmg` | Not notarized: on first launch right-click → **Open**, or `xattr -d com.apple.quarantine /Applications/Resolvr.app` |
| Linux | `Resolvr_0.1.0_amd64.AppImage`, `Resolvr_0.1.0_amd64.deb`, `Resolvr-0.1.0-1.x86_64.rpm` | No native window blur; secrets are stored in the library file |
| Windows | `Resolvr_0.1.0_x64-setup.exe`, `Resolvr_0.1.0_x64_en-US.msi` | Same as Linux |

Later versions install themselves: the app checks this page after launch and offers a one-click update. Builds are signed with the project key; an update with a bad signature will not install.

## Highlights

**Never lose state.** Every tab, draft, cursor position and panel size is written atomically and comes back after a restart or a crash — including `kill -9`.

**Workspaces you can commit.** `~/Resolvr/workspaces/<name>/` is plain `.graphql` and JSON. Clone a teammate's workspace into that folder and you have the team's collections; personal data (tokens, history, layout) never lands in the shared files — a `.gitignore` is generated for you.

**Environments that log in for you.** Point an environment at a flow that obtains a token: Resolvr stores it, refreshes it before expiry and retries a request after re-login when the server rejects the token. Mark an environment as production and every mutation or flow on it asks for confirmation first.

**Flows as smoke tests.** Chain operations, extract values by path and assert on responses. **Run all** executes every flow in the workspace and opens a report tab; **Copy report** gives Markdown for a ticket or a chat.

**Schema tools.** Introspection with a freshness indicator, autocomplete that scaffolds required arguments and variables, click-to-build operations from the schema browser, diff against the previous snapshot after a deploy.

**Everyday ergonomics.** Response search (⌘F) that filters the tree to matches, copy as curl (with or without secrets), `resolvr://` links that open an exact operation on a colleague's machine, drag-and-drop between collections, close tabs to the left/right/others, subscriptions over `graphql-ws`.

**Agent access.** An MCP server is bundled into the app (Settings → About → Copy command). It uses the same library and run engine; every call must state its intent, and the app shows the full activity log (⌘⇧A) — plan, each step and its result.

**macOS native.** Vibrancy, overlay title bar, light and dark themes, a left activity rail for collections, schema, history and flows.

## Storage and secrets

Tokens live in `~/Resolvr/.secrets/<workspace>.json` with owner-only permissions (`0600`) — the same model as SSH keys — or in macOS Keychain if you switch the setting. Secret values are masked everywhere a response leaves the engine: history, headers panel, agent log, MCP responses.

## Known limitations

- macOS builds are not notarized (no Apple Developer account), hence the one-time Gatekeeper step.
- Linux and Windows builds are produced by CI but have had less hands-on testing than macOS.
- Keychain storage is macOS-only; other platforms use the library file.
