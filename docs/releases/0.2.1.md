# Resolvr 0.2.1

A fix for updating from 0.2.0.

## Fixed

**"Signature Verification Failed" when installing an update.** The release manifest (`latest.json`) is what the updater checks a download against. It used to be written by each platform build in parallel, and a second CI run on the same tag could leave the manifest with a signature from the earlier run while the archive came from the later one — the file no longer matched its signature, and the update was rejected. The manifest is now built once, after all builds finish, from the signatures next to the uploaded files.

If 0.2.0 failed to update on macOS, this release installs normally. You can also install the DMG below by hand — settings, collections and history are kept.

Everything else is identical to [0.2.0](https://github.com/hojttaler/Resolvr/releases/tag/v0.2.0).
