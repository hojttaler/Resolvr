# Resolvr 0.2.5

A stability fix for Linux.

## Fixed

**Crash on Linux with `malloc(): unaligned tcache chunk detected`.** The native menu was rebuilt every time the app started and every time a setting changed — theme, font size, opacity. Replacing a GTK menu tears down its keyboard shortcuts and could corrupt memory, which ended in a crash some time later. The menu is now built once, in the language from your settings, and rebuilt only when you switch the interface language.

Everything else is identical to [0.2.4](https://github.com/hojttaler/Resolvr/releases/tag/v0.2.4).
