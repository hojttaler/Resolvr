# Resolvr 0.2.9

A fix for the crash on Linux.

## Fixed

**Linux: crash with `malloc(): unaligned tcache chunk detected`.** Resolvr could close by itself after a few minutes of work on Linux. Backtraces with symbols (added in 0.2.8) showed every crash at the same spot: the webview answering a call from the interface through the `ipc://` URI scheme. On Linux the interface now talks to the app through `postMessage` instead — the fallback transport built into Tauri, which answers on the main thread. macOS and Windows are unchanged.

If Resolvr still crashes on Linux after updating, please open an issue with the log (**Resolvr → Open Logs**) and, if you can, a backtrace:

```
gdb -batch -ex "handle SIGUSR1 nostop noprint pass" -ex run -ex "thread apply all bt 25" --args resolvr > resolvr-crash.txt 2>&1
```

Everything else is identical to [0.2.8](https://github.com/hojttaler/Resolvr/releases/tag/v0.2.8).
