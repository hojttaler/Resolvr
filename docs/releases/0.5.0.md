# Resolvr 0.5.0

## Request scripts and HMAC signing

Pre-request and post-request JavaScript can be configured per saved request or
per environment. Pre-request scripts can prepare variables and headers.
Post-request scripts can assert conditions against the response.

The script editor completes GraphQL input fields, response paths from the
operation, and HTTP header names. **Modules → Insert import** adds
`@resolvr/crypto` to Pre-request. The module signs the supplied string with
HMAC-SHA256 using a secret from the selected environment.

MCP agents can read and edit either phase with `scripts_get` and `scripts_set`.
The version returned on read can be supplied on update to detect edits made in
the meantime.

## Flows and workspaces

- A flow and its individual steps can select their own endpoints. The endpoint
  shown in the workbench is the fallback when none is assigned.
- Requests and flows prompt for missing template variables before proceeding.
- Workspace settings group endpoints and environments into separate sections.
  Workspace deletion is available in **General** and requires confirmation.

## Agent activity and schema

- The activity panel shows named tasks, calls in progress and readable results.
  It follows new actions and preserves a selection made by hand.
- The app picks up changes to saved requests, flows and configuration while it
  is open.
- The Schema Explorer loads additional fields on scroll, and field pickers
  mark fields already present in the request or variables.
