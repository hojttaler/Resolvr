# Resolvr 0.2.6

The MCP server bundled with the app now starts on Node.js 20.

## Fixed

**MCP server: "Cannot use import statement outside a module".** The server inside the app is an ES module, but the app did not mark it as one, so Node.js 20 refused to load it and Claude Code reported the server as failed to connect. Node.js 22 guessed the format by itself, which is why not everyone saw it. The app now ships the server as an ES module package; the command stays the same:

```
claude mcp add resolvr -s user -- node "/Applications/Resolvr.app/Contents/Resources/mcp/index.js"
```

Settings → About → **Agent via MCP** copies the command with the right path for your system.

Everything else is identical to [0.2.5](https://github.com/hojttaler/Resolvr/releases/tag/v0.2.5).
