# Resolvr 0.2.7

AI agents can now build flows through MCP.

## Flows through MCP

An agent connected to Resolvr's MCP server could list and run flows but not create them. Three new tools close the gap:

- **`flow_save`** creates or overwrites a flow. Each step is a saved operation (`operationRef`) or an inline query, with variables (`{{token}}` takes a value extracted by an earlier step or from the environment), `extract` to pass values on, `assert` to check the response and `continueOnFailure`.
- **`flow_get`** returns a flow in full, so an agent can extend it without losing steps.
- **`flow_delete`** removes a flow.

Before a flow is written, Resolvr checks that every referenced operation, environment and endpoint exists and reports all problems at once — a typo in a reference no longer shows up only when the flow runs. Flows created by an agent appear in the app immediately, like operations.

Connect the agent: Settings → About → **Agent via MCP**, or

```
claude mcp add resolvr -s user -- node "/Applications/Resolvr.app/Contents/Resources/mcp/index.js"
```

Everything else is identical to [0.2.6](https://github.com/hojttaler/Resolvr/releases/tag/v0.2.6).
