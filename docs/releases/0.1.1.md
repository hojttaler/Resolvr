# Resolvr 0.1.1

A follow-up to the first release: the interface now speaks English and Russian, keyboard shortcuts match the platform, and the window is opaque by default everywhere.

This is the first version delivered through the built-in updater — Resolvr 0.1.0 shows an update banner a few seconds after launch; one click downloads, verifies the signature and restarts.

## What's new

**Interface language.** Settings → Appearance → Language: System, English or Russian. "System" follows the OS language. The choice applies immediately, including the native menu bar. Plural forms follow each language's rules.

**Platform-aware shortcuts.** Menu accelerators use Cmd on macOS and Ctrl on Windows and Linux; every shortcut label in the interface — buttons, tooltips, command palette — shows the right modifier for the current platform. Previously several shortcuts did not fire on Windows at all.

**Opaque window by default.** On Windows and Linux the window (including the menu bar) was transparent, because the transparency was designed around macOS vibrancy. The window is now opaque on every platform; transparency and the blur material remain available as a macOS-only setting.

## Fixes

- Deferred draft and session writes no longer run outside the app process (this made the test suite flaky on slower machines).
- Icons for Linux and Windows installers are now part of the bundle.
