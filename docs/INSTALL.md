# Resolvr — установка и первые шаги

GraphQL-клиент для команды: коллекции запросов в общем репозитории, окружения с
автоматическим получением токена, цепочки-smoke-тесты и доступ для агента через MCP.

## Установка

### macOS

1. Откройте `Resolvr-<версия>-universal.dmg` и перетащите приложение в `Applications`.
2. При первом запуске macOS сообщит, что приложение «не удалось проверить» — оно
   подписано без аккаунта Apple Developer. Это ожидаемо. Два способа открыть:
   - **правый клик** по Resolvr в `Applications` → **Открыть** → **Открыть**;
   - или в терминале: `xattr -d com.apple.quarantine /Applications/Resolvr.app`.

   Делается один раз; после этого приложение открывается как обычно.
3. Работает на Apple Silicon и Intel.

### Linux и Windows

Сборки `.AppImage` / `.deb` и `.msi` / `.exe` собираются в CI (`.github/workflows/build.yml`).
На этих системах нет нативного размытия окна и Keychain — секреты хранятся в файле
библиотеки (это режим по умолчанию).

## Первый запуск

Приложение создаёт библиотеку `~/Resolvr/`. Дальше два пути:

**Получить готовые коллекции команды** — склонировать общий репозиторий workspace:

```bash
cd ~/Resolvr/workspaces
git clone <репозиторий> <имя-workspace>
```

и перезапустить приложение (или переключить workspace в шапке). Личное в репозиторий
не попадает: `.gitignore` в библиотеке исключает секреты, историю, кэш схемы и
раскладку панелей.

**Начать с нуля** — «Создать workspace», указать URL эндпоинта; схема подтянется
интроспекцией.

## Окружения и токены

Настройки workspace (⌘⇧,) → **Окружения**:

- **Переменные** — подставляются как `{{имя}}` в заголовки, переменные запроса и шаги
  цепочек.
- **Заголовки** — для всех запросов окружения, например `authorization: Bearer {{accessToken}}`.
- **Авторизация** — цепочка, которая добывает токен. Кнопка в шапке запускает её,
  токен сохраняется и подставляется сам; истёкший токен обновляется заранее, а на
  ошибку авторизации запрос повторяется после нового логина.
- **Боевое (prod-guard)** — окружение помечается `PROD`, а мутации и цепочки на нём
  требуют подтверждения.

Токены хранятся в `~/Resolvr/.secrets/` с доступом только владельцу (Настройки →
Токены и секреты; там же можно переключиться на Keychain).

## Цепочки

Вкладка **Флоу** → «Создать цепочку». Шаги выполняются по порядку; значение из ответа
извлекается по пути (`data.login.accessToken`) и подставляется дальше как `{{имя}}`;
проверки (`exists`, `eq`, `contains`…) делают цепочку smoke-тестом.

**Запустить все** — прогоняет все цепочки workspace и открывает отчёт вкладкой;
«Скопировать отчёт» даёт Markdown для задачи или чата.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Выполнить | ⌘↩ |
| Сохранить операцию (на место) / Сохранить как… | ⌘S / меню «⋯» |
| Новая вкладка / закрыть | ⌘T / ⌘W |
| Палитра команд | ⌘K |
| Поиск по ответу | ⌘F |
| Форматировать запрос | ⌘⇧F |
| Настройки / настройки workspace | ⌘, / ⌘⇧, |
| Раскладка Classic / Inspector / Focus | ⌘1 / ⌘2 / ⌘3 |
| Журнал действий агента | ⌘⇧A |

Правая кнопка по вкладке — закрыть остальные / слева / справа / все. Правая кнопка по
операции в коллекциях — переименовать, дублировать, переместить, удалить, скопировать
ссылку. Операции можно перетаскивать между коллекциями.

## Ссылки на запросы

«Копировать ссылку» даёт `resolvr://open?workspace=…&operation=…`. Ссылка открывает
операцию у коллеги, если у него установлено приложение и есть тот же workspace.

## Агент (Claude Code)

MCP-сервер вложен в приложение и работает с той же библиотекой. Настройки →
**О программе** → «Скопировать команду» даёт готовую строку вида

```bash
claude mcp add resolvr -- node "/Applications/Resolvr.app/Contents/Resources/mcp/index.js"
```

Нужен Node.js 20+. Всё, что делает агент, видно в журнале ⌘⇧A: план, намерение
каждого вызова и результат.

## Если что-то не работает

Настройки → **О программе** → «Скопировать диагностику» — и приложите текст к
сообщению: там версия, система и путь библиотеки.
